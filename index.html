ArgoCast

2026 · Research

Forecasts the next temperature and salinity profile of an Argo ocean float in the Arabian Sea, about 10 days ahead, from its three most recent profiles. Each forecast comes with a physics check, calibrated uncertainty, an explanation and links to the real data behind it.

  • Physics-informed Bi-LSTM trained with a TEOS-10 stability penalty, so it almost never predicts heavier water sitting above lighter water: 0.02 to 0.04% unstable forecasts, against 0.8 to 12.3% for the other learned models.
  • Benchmarked against 12 baselines on 36,164 quality-controlled profiles from 321 floats, staying within 0.005 °C of the most accurate model.
  • Monte Carlo dropout intervals, recalibrated so the 95% band really covers about 95% of observations.
  • FastAPI back end and a React 19 app with forecast, map, explanation and benchmark views, plus a grounded chat that also works offline.
  • Python
  • PyTorch
  • FastAPI
  • React 19
  • TypeScript
  • TEOS-10

Voice Tetris

2026 · Real-time

Play Tetris with your voice. Spoken words like "left", "spin" and "drop" become key presses in real time, using speech recognition that runs fully offline on your own machine.

  • About 50 to 80 ms from spoken word to key press, using streaming recognition with Vosk.
  • Fuzzy matching handles common mishearings, for example "write" is read as "right"; saying "left left left" fires three moves.
  • Calibrates itself to your microphone and background noise. Works with the built-in Pygame Tetris or any Tetris game that uses the keyboard.

  • Pygame

Food Waste Prediction System

2025 · Applied ML

Predicts how much food a restaurant will waste so it can plan quantities and throw less away. It trains a range of models on the restaurant's history, compares them, and keeps the best one.

  • Finds models automatically: linear and tree models, random forest, XGBoost, LightGBM, CatBoost, an optional PyTorch network and an ensemble. Add a model file and it is picked up with no code changes.
  • 7-day forecasts with confidence intervals, plus weather and special-event adjustments.
  • Manages several restaurants, each with its own models, and adapts most CSV layouts to one standard format.
  • Uses the GPU when one is available and falls back to the CPU otherwise.

DQN Snake Game AI

2026 · Reinforcement learning

An agent that teaches itself to play Snake by trial and error. It gets a reward for eating food and a penalty for crashing, and over many games it learns which moves pay off.

  • Deep Q-Network in PyTorch with experience replay and a separate target network to keep training stable.
  • Sees the game as 11 simple signals: danger ahead or to either side, current direction, and where the food is.
  • Evaluated against a random agent and a simple rule-based agent.
